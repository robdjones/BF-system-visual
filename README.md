# Bloomfilter · System motion prototype

Two isolated, looping, scrubbable motion scenes that explain the Bloomfilter system idea without narration.

- **Stage 1 — Unorganized systems pile**: tools, records and measures as a disconnected mess. Irregular accretion, independent drift, no shared rhythm.
- **Stage 2 — Transform**: the mess is captured to one gate, released on a beat into lanes (sequencing), then resolved into uniform units (normalizing) inside a steadily growing container.

Open `index.html` for the chapter viewer (mounts one scene at a time), or `stage-1-pile.html` / `stage-2-transform.html` for each scene on its own. No build step; plain HTML + SVG + JS.

Live link (private artifact, single file): https://claude.ai/artifact/WtEp2WFdeAvGQm7ShDgKR1

See `NOTES.md` for the locked visual kit, motion grammar and the improvement-pass log. `node build.mjs` regenerates `dist/`.
